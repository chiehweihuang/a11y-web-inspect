Ship interfaces everyone can use — and prove it.

Beacon is an accessibility + AEO inspection plugin for AI coding agents (Claude Code and Codex). It scores pages 0–100 across ten categories, anchors every finding to the exact markup that caused it, and publishes the benchmark data behind its own scoring.

A high score means automated checks found fewer issues in the evidence available. It is a triage signal — not a compliance certificate, and never a substitute for testing with disabled users.

One plugin, three moments

Accessibility is cheapest before code exists and most expensive after launch. Beacon meets you at all three points.

Before you code

beacon:guide

Accessible patterns, contrast-safe palettes, typography and motion tokens, and design tradeoffs — while the UI is still a sketch.

While you code

beacon:advisor

A hook reviews every UI edit in real time and hands the agent a concrete checklist for the file it just touched.

After you code

beacon:inspect

A Lighthouse-style 0–100 report with exact-markup fixes, legal context for six jurisdictions, and before/after comparison across runs.

Numbers that carry their own receipts

Most tools ask you to trust their score. Beacon ships the validation charter and the measurements in the repository, so every claim below is reproducible from a checkout.

coverage % every score states how much was actually measured; no evidence means a state, never a number

14/55 criteria Beacon's own measured WCAG 2.2 A+AA criterion coverage (25.5%), 2 fully decided within automation's reach (3.6%) — a different denominator from the recall table above (criteria, not instances); industry estimates put automated tools generally at ~30-40%

Lighthouse is a concurrent reference, not ground truth; recall is relative to the machine-checkable candidate pool. Method, judgement rules, adversarial re-verification, and raw inventories: VALIDATION.md and benchmark/. WCAG criterion coverage, row by row: coverage table.

Every detector carries its own measured precision

A score is only as trustworthy as the individual checks under it. Each detector is sampled across distinct real sites nobody hand-picked, judged instance by instance against the markup it cited, then adversarially re-judged by a second reviewer briefed to overturn the first.

Wild-sample precision, 15 instances per detector drawn across distinct sites (2026-08)
Detector Precision 95% CI
Image alt text1.0000.78–1.00

Clickable non-button0.6150.36–0.82

Input label0.4170.19–0.68

Publishing the weak rows is the point: n=15 ranks detectors and exposes error classes, it does not certify any single figure. The leading cause of false positives is markup hidden by a stylesheet class rather than an inline style, which a tier that never loads CSS cannot see. Every per-instance judgement — including the ones the reviewer overturned — ships with the published data.

Will it fight your design?

Findings fall into three buckets, by their effect on the page's default appearance.

No pixels alt text, accessible names, label associations, heading levels, page language, structured data
State-only appear only in a state the user chose — keyboard focus, a narrow window, reduced motion
Copy, not style link wording or a CAPTCHA mechanism — content decisions, not visual ones

Most accessibility debt is invisible to people it doesn't block. Fixing it doesn't touch your aesthetic — and this page is the demonstration: it is styled freely, audited by the engine it advertises, and the report is one click away.

Install

One command inside Claude Code, after registering the marketplace.

/plugin install beacon@beacon

The format is plugin@marketplace. This repository is both the marketplace and its only plugin, and both are named beacon — hence the doubled name.

Add the marketplace to your Claude Code config first:

"extraKnownMarketplaces": {
  "beacon": {
    "source": { "source": "github", "repo": "chiehweihuang/beacon" }
  }
}

Using Codex instead? Install it as a native Codex plugin:

codex plugin marketplace add chiehweihuang/beacon
codex plugin add beacon@beacon

Restart Codex after installation. See ADAPTERS.md for the runtime differences.
